让文字被看见，让声音被听见。

KIGTTS 将大字幕、语音交流与创作工具放在一起，也为每个人留出自由扩展的空间。

**[获取 KIGTTS 与插件](https://lht02.github.io/KPM/)** · **[开发插件](https://github.com/KIGTTS/plugin-sdk)** · **[浏览所有仓库](https://github.com/orgs/KIGTTS/repositories)**

### 从这里开始

- [KPM 插件商店](https://github.com/KIGTTS/plugin-package-store) · 发现、安装和更新插件。
- [AI 助手](https://github.com/KIGTTS/plugin-cloud-agent) · 对话、创作与软件操作。
- [语音合成服务](https://github.com/KIGTTS/plugin-speech-service) · 选择声音，让文字开口。
- [语音识别服务](https://github.com/KIGTTS/plugin-recognition-service) · 语音输入与聆听字幕。

### 一起创作

从 [插件 SDK 与开发文档](https://github.com/KIGTTS/plugin-sdk) 开始，也可以通过 [Lua 运行时](https://github.com/KIGTTS/plugin-lua-runtime) 和 [插件编辑器](https://github.com/KIGTTS/plugin-native-builder) 制作自己的工具。

各项目独立维护，许可请查看对应仓库的 `LICENSE` 与 `NOTICE`。
